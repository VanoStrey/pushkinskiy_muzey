# Техническая спецификация: Каталог официальных маршрутов и проверка уникальности

Документ является единым источником истины по архитектуре, хранилищу и алгоритмам проверки уникальности для проекта персональных маршрутов по ГМИИ им. А.С. Пушкина.

---

## 1. Контекст и архитектура

В рамках платформы персонализированных экскурсий генерируемые пользователям маршруты должны быть оригинальными и адаптированными, а не слепо повторять существующие официальные аудиогиды и экскурсионные программы музея. 

Для этого сервис выполняет две задачи:
1. **Импорт и каталогизация официальных маршрутов ГМИИ им. А.С. Пушкина** из публичных официальных источников (`pushkinmuseum.art/media/guides/`, платформы `tmatic.travel`, `ar.culture.ru` / ARTEFACT).
2. **Проверка уникальности вновь создаваемого маршрута** относительно официальных маршрутов по многоуровневому алгоритму (хеши последовательностей, множество экспонатов, коэффициент Жаккара, пересечение тем и названий).

## 2. Схема хранения в YDB

Таблица: `official_routes`

### YQL DDL
```yql
CREATE TABLE IF NOT EXISTS official_routes (
    id Utf8,
    title Utf8,
    description Utf8,
    source_url Utf8,
    source_name Utf8,
    collected_at Utf8,
    sequence_hash Utf8,
    set_hash Utf8,
    exhibit_ids Json,
    stops Json,
    verification_status Utf8,
    completeness_score Double,
    PRIMARY KEY (id)
);
```

### Описание полей

| Поле | Тип YQL | Описание |
| :--- | :--- | :--- |
| `id` | `Utf8` | Стабильный нормализованный идентификатор (PRIMARY KEY) |
| `title` | `Utf8` | Нормализованное название официального маршрута |
| `description` | `Utf8` | Официальное описание программы или гида |
| `source_url` | `Utf8` | Канонический URL страницы источника |
| `source_name` | `Utf8` | Название источника (напр., `pushkinmuseum.art/media/guides`) |
| `collected_at` | `Utf8` | Дата сбора/актуализации в формате ISO 8601 UTC |
| `sequence_hash` | `Utf8` | SHA-256 от упорядоченной последовательности идентификаторов |
| `set_hash` | `Utf8` | SHA-256 от отсортированного множества уникальных идентификаторов |
| `exhibit_ids` | `Json` | Массив идентификаторов экспонатов в порядке следования |
| `stops` | `Json` | Детальный массив остановок (зал, экспонат, автор, провенанс) |
| `verification_status`| `Utf8` | `verified` (полная сверка) или `partial` (частичная сверка) |
| `completeness_score` | `Double` | Коэффициент полноты данных (от 0.0 до 1.0) |

## 4. Алгоритм и правила определения уникальности

Функция сравнения:
`check_route_uniqueness(new_route_exhibit_ids: list[str], new_route_title: str = "") -> RouteComparisonResult`

### Уровни совпадения:

1. **Полное совпадение последовательности (`exact_sequence`)**:
   - `new_sequence_hash == official.sequence_hash`
   - Итог: `is_unique = False`, `similarity_score = 1.0`
   - Описание: Новый маршрут полностью копирует официальный маршрут музея в том же порядке остановок.

2. **Перестановка тех же экспонатов (`permutation`)**:
   - `new_set_hash == official.set_hash` (при `len(new_set) == len(official_set)`)
   - Итог: `is_unique = False`, `similarity_score = 1.0`
   - Описание: Состав произведений полностью идентичен официальному маршруту, изменён только порядок залов.

3. **Существенное пересечение (`significant_overlap`)**:
   - Вычисляется коэффициент Жаккара:
     $$J(A, B) = \frac{|A \cap B|}{|A \cup B|}$$
     и доля совпадения с новым маршрутом:
     $$O(A, B) = \frac{|A \cap B|}{|A|}$$
   - Если $J \ge \text{threshold}$ или $O \ge \text{threshold}$ (по умолчанию $\text{threshold} = 0.5$, настраивается через переменную `ROUTE_OVERLAP_THRESHOLD` в `Settings`):
   - Итог: `is_unique = False`, `similarity_score = max(J, O)`
   - Описание: Маршрут в значительной степени повторяет официальную программу.

4. **Тематическое / смысловое совпадение названия (`title_theme_similarity`)**:
   - Проводится нормализация строк и токенизация названий.
   - Если текстовое сходство (по токенам) превышает 0.65 при наличии хотя бы 1 общего экспоната:
   - Итог: `is_unique = False`, `similarity_score = token_similarity`
   - Описание: Название и состав пересекаются с официальным туром.

5. **Оригинальный маршрут (`unique`)**:
   - Ни одно из вышеуказанных условий не выполнено.
   - Итог: `is_unique = True`, `similarity_score = max_observed_overlap`

## 5. Источники данных и границы покрытия

### Покрываемые источники:
- **Официальный портал ГМИИ:** `https://pushkinmuseum.art/media/guides/index.php?lang=ru`
- **Платформа tmatic.travel (официальный партнер ГМИИ):** постоянные экспозиции Главного здания и Галереи XIX–XX вв., детские квесты, тематические маршруты.
- **Платформа ARTEFACT (Минкультуры РФ / ГМИИ):** «Как устроены шедевры XIX–XX веков».
- **izi.TRAVEL:** исторические обзоры коллекций.

### Ограничения и неполнота данных:
1. Часть аудиогидов по временным выставкам архивируется и недоступна в постоянной экспозиции.
2. В некоторых обзорных аудиогидах экспонаты упоминаются в связке залов без точного инвентарного номера в тексте страницы — для них фиксируется `verification_status: "partial"`.
3. Идемпотентный импортер работает как из локального верифицированного снимка данных (snapshot), так и с возможностью онлайн-актуализации.
